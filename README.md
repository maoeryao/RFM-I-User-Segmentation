# 电商平台高价值流失用户召回分析 (RFM-I 优化模型 & A/B 实验)

## 📌 项目背景
传统 RFM 模型仅基于历史消费（M）评估价值，导致大量“高收入、高意向但当前消费低”的潜力用户被误判为低价值。本项目旨在构建 **RFM-I 增量模型**，并通过 **A/B 实验** 验证其在降低营销成本、提升 ROI 方面的业务价值。

## 🔍 核心业务洞察与解决方案
1. **意向度 (I-Score) 指标设计**：将“浏览时长”与“浏览页数”归一化加权求和，精准量化购买意愿。意向高的用户只需一张券或一次降价即可转化。
2. **活跃连接度 (三档划分)**：打破了传统的二元订阅指标，识别出“僵尸订阅”（订阅但30天未登录）与“无订阅但高活”的隐形活跃者，剔除了无效营销对象。
3. **发现盲区群体**：模型成功挖掘出**“纠结土豪”**（高收入、高意向、低当前消费），此类人群在传统模型中被严重低估。

## 🧪 A/B 实验与商业价值
基于真实电商用户特征数据集进行策略对比：
 **传统 RFM 策略**：触达 110 人，营销成本 1100 元，边际收益 840 元，**边际 ROI 为 -23.6%**（亏本）。
 **优化 RFM-I 策略**：精准触达 110 人，营销成本同样 1100 元，边际收益 1500 元，**边际 ROI 达 36.4%**（扭亏为盈）。
*注：受限于实验样本量（N=110），P值为 0.0775。虽未达统计显著阈值，但业务 ROI 的质变证明了策略的有效性，后续需扩大流量池验证。*

## 💻 技术栈与使用说明
 **语言/工具**：Python (Pandas, NumPy, SciPy)
 **分析方法**：数据清洗、RFM 模型、Min-Max 归一化、卡方检验 (Chi-Square Test)
